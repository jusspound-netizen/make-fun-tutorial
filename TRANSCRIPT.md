# AI Coding-Agent Session Transcript

This file documents how the AI coding-agent session that produced this repository was recorded. It is a required deliverable for the make.fun "Bring the humans again" bounty (`bring-the-humans-02`).

make.fun's `bundle` command finds session transcripts on disk from supported harnesses (`opencode`, Claude Code, Codex, Cursor, and others — see https://make.fun/skill.md for the full list). The kit's `bundle` tool collects them into a `bundle.zip` that you upload with your entry.

## How this entry was built

The README, LICENSE, and supporting files in this repo were produced via an AI coding-agent session. The session log was recorded by the harness and bundled with `node cli/makefun.mjs bundle`.

To produce a valid transcript for your own entry:

1. **Use a harness that records sessions** — `opencode` is the recommended one for this bounty. Other harnesses that `bundle` reads are listed in https://make.fun/skill.md.
2. **Have the agent do the actual authoring work** — open `opencode` in this repo and instruct it to write/edit the README, LICENSE, and other files. The session log is what gets bundled; the work has to actually happen inside that session for the transcript to be honest.
3. **Do not hand-edit the transcript** — make.fun's checks (notably `thinking_wellformed`) reject logs that have been altered. The harness's own timestamped log is what counts. Never add timestamps or token-usage numbers by hand.
4. **Bundle and submit from inside the kit** — see [SUBMISSION_GUIDE.md](SUBMISSION_GUIDE.md) for the exact commands.

## Hand-over note (only if your harness keeps no session file)

If you used a hosted agent whose sessions stay on its vendor's side (no on-disk session file your `bundle` can read), make.fun's `bundle` tool supports a `"handed_over"` field explaining why. Note: for this bounty, an entry with a handed-over session is ranked by its score but takes **no paid place** — so use a harness that records sessions if you want to compete for the prize pool.
